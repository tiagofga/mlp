Modular MLP in C++

An academic-focused, from-scratch multilayer perceptron project in modern C++ with both a CLI application and an installable CMake library package.

View Repository CI Workflow

Highlights

  • C++17 project focused on reproducible academic experiments.
  • CPU-first execution with optional OpenMP, BLAS/CBLAS, and CUDA paths.
  • BLAS path includes an automated 512x512 benchmark gate for issue #4.
  • Installable package with find_package(mlp) support.
  • Multiple optimizers, metrics, IO, and example applications.

Quick Start

cmake -S . -B build
cmake --build build
./build/mlp
cmake -S . -B build-blas -DMLP_ENABLE_BLAS=ON
cmake --build build-blas
./build-blas/mlp_dense_benchmark --min-speedup 2.0
