Current capabilities

Small enough to inspect, structured enough to extend

The project keeps neural-network mechanics explicit while still treating build, packaging, testing, numerical validation, and backend selection as first-class engineering concerns.

Architecture

Small modules, clear data flow

Sequential owns the layer stack. Forward propagation produces predictions, the loss starts backpropagation, and optimizers update trainable parameters through explicit parameter/gradient references.

Input→ Dense→ Activation→ Dense→ Prediction
Target→ Loss→ Backward gradients
Parameter refs→ Optimizer→ Updated weights

C++ API

Build a network with explicit components

The public surface stays deliberately small while the training mechanics remain inspectable.

Minimal model
std::mt19937 rng(42);

mlp::Sequential model;
model.add(std::make_unique<mlp::Dense>(2, 16, rng));
model.add(std::make_unique<mlp::Tanh>());
model.add(std::make_unique<mlp::Dense>(16, 1, rng));
model.add(std::make_unique<mlp::Sigmoid>());

mlp::Adam optimizer(0.01);

Local workflow

Build, run, validate

Quick start 
cmake -S . -B build
cmake --build build
./build/mlp
ctest --test-dir build --output-on-failure
BLAS benchmark 
cmake -S . -B build-blas -DMLP_ENABLE_BLAS=ON
cmake --build build-blas
./build-blas/mlp_dense_benchmark --min-speedup 2.0
