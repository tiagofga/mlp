What it gives you

A compact lab for learning, benchmarking, and embedding MLPs

The code favors readable math, deterministic tests, and package-friendly boundaries. It is small enough to inspect end to end, but structured enough to grow through issues and experiments.

01

Experiment CLI

Train XOR-style datasets with configurable hidden layers, optimizers, splits, seeds, and thresholds.

02

Library API

Consume stable `include/mlp/*` headers and exported CMake targets from downstream C++ projects.

03

Verification-first

Use unit tests, shared matrix assertions, finite-difference gradient checks, package tests, and CI checks.

04

Backend switches

Keep the scalar CPU path by default, then enable OpenMP, BLAS, or CUDA when the experiment calls for it.

Architecture

Small modules, clear data flow

`Sequential` owns layers, losses expose forward/backward contracts, and optimizers step through layer parameter references. Recent cleanup centralizes optimizer traversal and shared test assertions.

Local workflow

Build, run, validate

Quick start 
cmake -S . -B build
cmake --build build
./build/mlp
ctest --test-dir build --output-on-failure
BLAS benchmark 
cmake -S . -B build-blas -DMLP_ENABLE_BLAS=ON
cmake --build build-blas
./build-blas/mlp_dense_benchmark --min-speedup 2.0
