Build, benchmark, and reuse a from-scratch multilayer perceptron with a CLI workflow, installable CMake package, and optional accelerated compute backends. Built for students, educators, and engineers who want transparent ML fundamentals without framework black boxes.

Why this project

Focused features without framework overhead

Motivation: make neural-network experimentation reproducible and inspectable in modern C++. This project is a modular MLP implementation for people learning, teaching, benchmarking, and integrating simple models into larger CMake-based systems.

Training and evaluation

Run XOR-style experiments with configurable hidden layers, optimizers, dataset splits, metrics, activation layers, and loss functions (BinaryCrossEntropy) backed by dedicated unit tests and finite-difference gradient checks.

Acceleration paths

Start on CPU, enable OpenMP for parallelism, or switch on BLAS and CUDA when you want faster dense operations, including the 512x512 BLAS benchmark gate used in CI validation.

Package-friendly design

Consume the project through exported CMake targets or stable public headers in downstream applications.
