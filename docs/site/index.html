Modern C++ for reproducible MLP experiments

Build, benchmark, and reuse a from-scratch multilayer perceptron with a CLI workflow, installable CMake package, and optional accelerated compute backends.

Project overview

C++17 Core implementation
CPU + GPU OpenMP, BLAS, CUDA options
Installable CMake package with find_package

Quick start

cmake -S . -B build
cmake --build build
./build/mlp

./scripts/pre_push_check.sh

BLAS benchmark

cmake -S . -B build-blas -DMLP_ENABLE_BLAS=ON
cmake --build build-blas
./build-blas/mlp_dense_benchmark --min-speedup 2.0

Built for

  • Academic experimentation
  • Reproducible training runs
  • Activation, loss, and gradient-check coverage
  • Library reuse in larger CMake projects

Why this project

Focused features without framework overhead

Training and evaluation

Run XOR-style experiments with configurable hidden layers, optimizers, dataset splits, metrics, activation layers, and loss functions (BinaryCrossEntropy) backed by dedicated unit tests and finite-difference gradient checks.

Acceleration paths

Start on CPU, enable OpenMP for parallelism, or switch on BLAS and CUDA when you want faster dense operations, including the 512x512 BLAS benchmark gate used in CI validation.

Package-friendly design

Consume the project through exported CMake targets or stable public headers in downstream applications.

Build workflow

Go from clone to validated run in minutes

01

Configure and build

Generate the build directory with CMake and compile the CLI plus library targets.

02

Run experiments

Launch the executable locally to inspect training loss, validation behavior, and test metrics.

03

Validate changes

Use the pre-push script to rebuild and rerun the repository test suite locally. CI also enforces Valgrind leak checks and benchmark gates before changes land.
